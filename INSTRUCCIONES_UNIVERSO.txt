SIGA — EL UNIVERSO DEL VÍNCULO
Instrucciones de integración
==============================

¿QUÉ SE AGREGÓ?
---------------
Módulo nuevo: "🌌 Nuestro Universo"
Un mapa visual interactivo de la relación que lee datos
ya existentes en SIGA (recuerdos, playlist, carta, etc.)
y los representa como nodos de un universo espacial.


ARCHIVOS NUEVOS
---------------
backend/routes/universo.js        — API del módulo
backend/public/css/universo.css   — Estilos completos
backend/public/js/universo.js     — Lógica del canvas + SVG + modales
SQL_UNIVERSO.sql                  — Tablas opcionales (ver abajo)


ARCHIVOS MODIFICADOS
--------------------
backend/server.js
  → Agrega: app.use('/api/universo', require('./routes/universo'));

backend/public/index.html
  → Link CSS universo.css
  → Script JS universo.js
  → Nav item "🌌 Nuestro universo" en sidebar
  → Sección <section id="page-universo"> completa
  → Tarjeta de acceso en el dashboard

backend/public/js/app.js
  → 'universo' en el mapa de navegación
  → initUniverso() / destroyUniverso() en navigateTo()


RUTAS API NUEVAS
----------------
GET  /api/universo           → Estado y conteos de todos los nodos
GET  /api/universo/eventos   → Eventos procedurales activos (cometas, auroras, etc.)
GET  /api/universo/nodo/:id  → Datos detallados de un nodo específico
GET  /api/universo/sigy      → Mensaje contextual de SIGy para el universo

IDs de nodo válidos:
  islas | bosque | biblioteca | puertas | rincon | constelaciones | puentes


MAPEO DE DATOS
--------------
🪐 Islas del Primer Encuentro → tabla recuerdos
🎵 Bosque de las Canciones    → tabla playlist
📚 Biblioteca de Secretos     → tabla carta
🚪 Puerta del Futuro          → tabla promesas
✨ Constelaciones              → tabla razones
🌙 Rincón de la Calma         → tabla espacio_registros
🌉 Puentes de encuentro       → tabla tiempo_disponibilidad


SQL (OPCIONAL)
--------------
SQL_UNIVERSO.sql agrega 3 tablas de persistencia opcionales.
El módulo funciona completamente SIN ejecutarlo.
Solo es necesario si en el futuro se quiere guardar
descubrimientos manuales o estado por usuario.


COMPATIBILIDAD
--------------
✅ No modifica tablas existentes
✅ No rompe rutas existentes
✅ No cambia estilos globales
✅ Canvas se destruye al salir de la sección (sin memory leaks)
✅ Compatible con modo móvil
✅ Usa variables CSS de style.css existentes
✅ SIGy integrado con imágenes ya existentes del proyecto
